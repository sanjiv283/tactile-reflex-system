# Reproducibility guide

Everything reported in this repository is regenerated by the commands below. Nothing needs hardware, Quartus or a network connection after the Python packages are installed.
Verified environment: Linux, Python 3.13.17, Icarus Verilog 12.0, Yosys 0.33, gcc 13.3. Times are approximate, observed on a 4-core machine.

## 1. Set up

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements-lock.txt      # exact versions; requirements.txt has ranges
sudo apt-get install iverilog yosys gcc                                       # or your platform's equivalent
```
`requirements-host.txt` (pyserial) is only needed to talk to a real serial port; every test uses a mock port.

The CI workflow `.github/workflows/ci.yml` runs the routine set. **It has never run**: nothing was pushed from the development environment, so treat it as untested.

## 3. What is deterministic

All results and generated files are deterministic (fixed seeds) **except** the machine-dependent inference timings in `results/ml_results.json` and `results/pred_results.json`, which are
measured only with `python3 ml/train_eval.py --timing` and otherwise preserved from the committed file. `tools/check_artifacts.py` compares everything else byte-for-byte or field-for-field.
Wall-clock times in logs vary and are not evidence.

## 4. Things that overwrite tracked files

`sh sim/run_all.sh` regenerates `results/sim_log.txt`, `results/sim_console.png`, trace plots and waveforms from the current sources. Run it in a scratch copy if you need the committed versions untouched. The `check_*` tools all work in temporary copies.

## 5. Backups and evidence preservation

Before the hardening work, a baseline backup was taken and verified (git bundle + tar.gz + SHA-256 manifest, timestamp `20261106T0838Z`) and is never overwritten. The final backup after this work is a separate timestamped set. Verify any of them with `sha256sum -c <file>.sha256`, then extract to an empty directory and compare with the manifest. The earlier 2026-10-28 backups are also preserved.

## 6. Known limits of reproducibility

* One machine, one tool version set (no independent replication). The CI workflow would add a second environment once run.
* Yosys numbers are generic mappings, not Quartus fits.
* The demo video is not regenerated by these commands (see `demo_video/README.md`).
* The Wokwi sketch and any hardware behaviour cannot be reproduced here.
